# LingoCode Studio for VS Code

Open this folder in VS Code and press **F5** to launch an Extension
Development Host. In the Command Palette choose **LingoCode: Open Source
File** or **LingoCode: Download Project ZIP**. Sign in with an existing
LingoCode Studio account when prompted. The extension opens source as an
untitled document so you can inspect or save it.

The default server is `http://127.0.0.1:8080`. For a hosted installation,
set **LingoCode: Server Url** in user settings to your HTTPS origin.
Sessions are stored using VS Code SecretStorage and scoped to that origin.
Use **LingoCode: Sign Out** to revoke this extension's session.
